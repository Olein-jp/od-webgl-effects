# プリセットの設計（Issue #6）

ユーザープリセットはブロック内の `odWebgl.userPresets` に保存する。サイト共有やユーザー設定には書き込まない。既存の投稿編集権限で保存・削除でき、追加のREST APIや権限は不要。投稿と同じ公開範囲であり、秘密情報を入れる用途には使わない。ブロックを複製・コピーすればプリセットも一緒に再利用できる。最大10件、名前80 Unicodeコードポイント、IDはuser-で始まる40文字以内の英小文字・数字・ハイフン。削除はそのブロックの一覧だけに適用し、現在の描画設定は保持する。

保存するのはエフェクトID・名前・ID・検証済みsettingsだけ。performance・fallbackは変更しない。未知エフェクト、不正ID、重複IDを除外し、PHP/JSの共通スキーマで取り込み直す。テーマカラー参照は維持。userPresetsがないPhase 1属性にはフィールドを追加しない。

同梱プリセットは全エフェクトに3種類を用意し、固有値・パレットを含む。手動変更はCustomに戻る。エフェクト切替は共通の色・速度・強度・不透明度を保持して固有値だけ既定にする。プリセット適用・リセットはsettingsだけを検証済み値に置換し、無関係な性能・フォールバック・保存済みプリセットは保持する。1操作につき1回のsetAttributesで標準Undo/Redoに参加する。

選択肢は登録済みカテゴリだけ。標準SelectControlに加え、ラベルとaria-pressedを持つ標準Buttonで静止SVGを比較できる。通常のTab・Enter・Spaceで操作し、一覧用のCanvasは作らない。ライブ描画は選択中のブロックだけ。ラベルは静的な翻訳カタログを通す。
