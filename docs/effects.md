# エフェクトの設定

色は2〜5色。共通の速度は0〜3、強度は0〜2、不透明度は0〜1。全エフェクトは同じ描画管理、品質、停止、Reduced Motion、破棄処理を使用する。スキーマの数値範囲を超える値はPHP/JSで制限する。

| エフェクト | 固有設定と意味 |
| --- | --- |
| Aurora | ノイズ倍率0.1〜10、発光0〜2、回転0〜360度 |
| Fluid Gradient | 倍率0.1〜10、変形0〜2、混合0〜1、回転0〜360度 |
| Waves | 振幅0〜1、周波数0.1〜20、本数1〜12、線幅0.001〜0.1 |
| Mesh Gradient | 倍率0.1〜10、混ざりの減衰係数0.5〜6（小さいほど柔らかい）、色の配置範囲0.1〜2、回転0〜360度 |
| Ripple | 振幅0〜1、周波数1〜20、広がり0.2〜5（大きいほど波間隔が広い）、距離減衰0.1〜8 |
| Noise Field | ノイズ倍率0.1〜12、座標変形0〜2、回転0〜360度。決定的な補間ノイズを使用 |
| Animated Grid | 単位範囲の格子数2〜40、線幅0.005〜0.2、変形0〜1、変形の周波数0.1〜10 |

各モジュールは表示時に個別取得。静止時刻0で再現可能なため、編集画面と公開画面の比較に使用できる。サムネイルは静止SVGでCanvasを作らない。Mesh / Ripple / Noise / Gridには固有設定を含む3種のプリセットを同梱。ポインター起点のRippleはIssue #7で扱う。

`effects.spec.js`は各追加エフェクトの保存・再編集、3サイズの描画、品質切替、Reduced Motion、WebGL失敗時を検証。Chromiumの固定時刻画像は新規生成後に目視確認し、以降の差分検出に使用する。
